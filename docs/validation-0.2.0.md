# 0.2.0-preview kontrol kaydı

27 Ekim 2026. Bu kontroller klinik doğrulamanın veya bağımsız hekim incelemesinin yerine geçmez.

- JavaScript sözdizimi ve veri kontrolleri geçti: 40 benzersiz tanı, dört 10'lu grup, 10 tanıda 16 kaynaklı seçenek. Eksik ürün verisi yayın kapısından geçmiyor; tam reçete sayısı 0.

- Tinea cruris araması Türkçe karakter kullanılmadan “kasik mantari” ile bulundu. Tanılar arasında geçişte eski etken madde içeriği kalmadı.
- Tinea cruris için alerji seçildiğinde doz gizlendi. Pityriasis versicolor iki ayrı seçenek gösterdi; alerji seçiliyken ikisi de gizlendi.
- 320 piksel genişlikte açık tema, koyu/saf siyah temada çok büyük yazı ile kontrol yapıldı; yatay taşma görülmedi (belge genişliği 305 piksel). Geçici ekran boyutu ayarı kaldırıldı.
- Harici script/font/CDN bağımlılığı, reçete kopyalama ve PWA dosyası eklenmedi.
